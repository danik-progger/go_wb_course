# CommentTree - Древовидные комментарии с навигацией и поиском

CommentTree - это сервис для работы с древовидными комментариями, поддерживающий неограниченную вложенность и дополнительные функции вроде поиска, сортировки и постраничного вывода.

## Функциональность

Сервис поддерживает:

- Встроенные HTTP-методы:
  - `POST /comments` - создание комментария (с указанием родительского)
  - `GET /comments?parent={id}` - получение комментария и всех вложенных
  - `DELETE /comments/{id}` - удаление комментария и всех вложенных под ним
  - `GET /comments/search?q={query}` - поиск комментариев по ключевым словам

- Постраничную навигацию и сортировку при выводе комментариев (реализовано частично)
- Полнотекстовый поиск по комментариям
- Простой web-интерфейс, где можно:
  - Просматривать дерево комментариев с визуальной вложенностью
  - Создавать новый комментарий (и ответы)
  - Удалять комментарии
  - Искать комментарии по ключевым словам

## Структура проекта

- `main.go` - точка входа в приложение, веб-интерфейс
- `api/router.go` - HTTP-роутер и обработчики запросов
- `service/service.go` - бизнес-логика и работа с данными

## Запуск

1. Установите зависимости: `go mod tidy`
2. Запустите приложение: `go run main.go`
3. Откройте в браузере: `http://localhost:8080`

## API Примеры

### Создание комментария:
```bash
curl -X POST http://localhost:8080/comments \
  -H "Content-Type: application/json" \
  -d '{"text": "Это корневой комментарий"}'
```

### Создание дочернего комментария:
```bash
curl -X POST http://localhost:8080/comments \
  -H "Content-Type: application/json" \
  -d '{"parent_id": 1, "text": "Это ответ на комментарий 1"}'
```

### Получение комментариев:
```bash
curl http://localhost:8080/comments
```

### Получение дочерних комментариев:
```bash
curl "http://localhost:8080/comments?parent=1"
```

### Поиск комментариев:
```bash
curl "http://localhost:8080/comments/search?q=ключевое+слово"
```

### Удаление комментария:
```bash
curl -X DELETE http://localhost:8080/comments/1
```

## Web-интерфейс

Приложение включает веб-интерфейс с возможностью:
- Просмотра дерева комментариев с визуальной иерархией
- Добавления новых комментариев
- Ответов на существующие комментарии
- Удаления комментариев
- Поиска по ключевым словам
